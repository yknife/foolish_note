1. 关闭防火墙

   ```sh
   systemctl stop firewalld
   systemctl disable firewalld
   ```

2. 禁用和关闭 swap

   ```sh
   echo "vm.swappiness = 0">> /etc/sysctl.conf
   swapoff -a && swapon -a
   sysctl -p
   ```

3. 设置系统最大打开文件句柄数

   ```sh
   vi /etc/security/limits.conf 
   * soft nofile 1000000
   * hard nofile 1000000
   ```

4. 修改虚拟内存区域数量

   ```sh
   sysctl -w vm.max_map_count=2000000
   ```

5. 关闭透明大页

   ```sh
   echo madvise > /sys/kernel/mm/transparent_hugepage/enabled
   echo madvise > /sys/kernel/mm/transparent_hugepage/defrag
   ```

6. 安装mysql-client

   1. [下载地址](https://downloads.mysql.com/archives/community/)

   2. 下载rpm包

      * mysql-community-libs-5.7.28-1.el7.x86_64.rpm
      * mysql-community-common-5.7.28-1.el7.x86_64.rpm
      * mysql-community-client-5.7.28-1.el7.x86_64.rpm

   3. 创建目录

      ```sh
      mkdir /opt/software/mysql-client/
      ```

   4. 检查当前系统是否安装过 MySQL

      ```sh
      sudo rpm -qa|grep mariadb
      #如果存在，先卸载
      sudo rpm -e --nodeps mariadb mariadb-libs mariadb-server
      ```

   5. 安装

      ```sh
      rpm -ivh /opt/software/mysql-client/*
      ```

   6. 使用mysql-client连接FE

      ```sh
      mysql -h hadoop1 -P 9030 -uroot
      ```
